ALPHABET TRAIN — SEY GAMERZ MULTIPLAYER

This is the multiplayer web-game project.

Players:
1. Host creates a room.
2. The game generates an SG#### room code.
3. Players enter their name and the room code.
4. Everyone appears in the lobby.
5. The host starts the round.
6. Everyone receives the same letter/category.
7. The server validates answers and records the first correct submission.
8. The winner gets 1 point.
9. Host starts the next round.

To run:
- Install Node.js
- Open this folder in a terminal
- Run: npm install
- Run: npm start
- Open http://localhost:3000

For players on different phones/internet connections, deploy this Node.js project to a hosting service such as Render.
